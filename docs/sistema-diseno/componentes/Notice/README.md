# Notice

Aviso que explica en lenguaje simple por qué algo encaja, no encaja o necesita un dato más.

**Qué aporta quien lo usa:** un título que es la conclusión, una o dos frases con el motivo y qué hacer, y el tono (`encaja`, `revisar`, `no`, `info`).

- El título responde «¿y entonces?»; el párrafo dice qué hacer después.
- `revisar` siempre pide un dato concreto y explica cómo encontrarlo, sin abrir la PC si se puede.
- Usá `role="alert"` sólo para `no`; el resto es `role="status"`.
- `uj-notice-info` (fondo `papel-hundido`) para consejos neutrales.
