# PcSlots

Vista de la PC como nueve casilleros, uno por componente, para ver de un golpe qué hay, qué falta y qué está en duda.

**Qué aporta quien lo usa:** para cada una de las nueve categorías (procesador, placa madre, memoria, placa de video, fuente, gabinete, almacenamiento, cooler, ventiladores) su estado: cargada, en duda o vacía, y el nombre corto.

- Cargada: `papel-alto`, ícono sobre `pino-suave`.
- En duda (`is-unknown`): ícono sobre `revisar-fondo` y el nombre dice qué falta («16 GB · falta la velocidad»).
- Vacía (`is-empty`): borde punteado `linea-fuerte`, texto «Agregar» en `pino`; es un enlace.
- Tres columnas en escritorio, una en móvil. Siempre el mismo orden.
- Mostrar estas ranuras no guarda nada: la PC se guarda sólo cuando la persona confirma.
