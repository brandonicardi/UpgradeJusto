# UpgradeCard

La sugerencia principal: qué cambiar, por qué, cuánto cuesta y si encaja, en una sola tarjeta.

**Qué aporta quien lo usa:** la pieza actual y la nueva, dos o tres motivos en lenguaje simple, el precio con procedencia, cuánto sobra o falta del presupuesto y el veredicto del motor.

- Es la única tarjeta con `radius-lg` y `sombra-2`: hay una sola por pantalla.
- El título es una acción: «Cambiá la placa de video».
- «Hoy tenés» sobre `papel`, «Pasás a» sobre `pino-suave`.
- Lo que sobra del presupuesto se resalta con `lima`. Si falta plata, se dice en `tinta` sin resaltar: «Te faltan $ 40.000».
- Simular no guarda nada: el botón principal dice «Sumar a mi plan», no «Aplicar».
