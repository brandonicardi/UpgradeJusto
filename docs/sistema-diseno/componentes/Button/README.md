# Button

Botón en forma de píldora para avanzar, con tres pesos: principal, secundario y quieto.

**Qué aporta quien lo usa:** el texto (un verbo en voseo que dice qué pasa: «Ver qué me conviene», «Guardar mi PC»), un ícono opcional a la derecha y el estado deshabilitado.

- `uj-btn-principal`: relleno `pino`, texto `sobre-pino`. **Uno solo por pantalla.**
- `uj-btn-secundario`: `papel-alto` con borde `linea-fuerte`. Para la alternativa razonable.
- `uj-btn-quieto`: sólo texto subrayado en `pino`. Para salidas («Prefiero mirar el catálogo»).
- `uj-btn-chico`: 40px de alto, dentro de tarjetas y listas.
- Deshabilitado: el texto explica qué falta («Elegí un objetivo primero»), nunca sólo «Continuar» en gris.

No: dos principales juntos, textos genéricos («OK», «Enviar»), íconos sin texto.
