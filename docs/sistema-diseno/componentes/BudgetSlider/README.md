# BudgetSlider

Control para elegir el presupuesto máximo, con el monto grande arriba y atajos redondos debajo.

**Qué aporta quien lo usa:** mínimo, máximo, paso, moneda, valor actual y los atajos.

- El monto se escribe completo en la familia `display` a 34px; la moneda al lado en `tinta-suave`.
- Pista `papel-hundido`, tramo elegido `pino`, perilla `papel-alto` con borde `pino`.
- Los atajos (chips) son montos redondos que la gente piensa: «$ 500 mil».
- Debe poder escribirse el monto también: ofrecé un campo si el rango es muy amplio.
