# PlanSteps

Lista vertical de etapas de compra que muestra qué ya hiciste, en qué paso estás y qué viene.

**Qué aporta quien lo usa:** etapas ordenadas con nombre simple, costo, estado (hecha, actual, pendiente) y el veredicto de la PC acumulada hasta ese paso.

- Hecha: círculo `pino` con tilde. Actual: círculo `lima` y cuerpo sobre `pino-suave`. Pendiente: círculo `papel-hundido`.
- Cada etapa se valida sobre el resultado de las anteriores; el veredicto que se muestra es el de la PC con todos los cambios hasta ahí.
- El costo de cada etapa siempre a la vista; el total, arriba de la lista con `PriceTag`.
