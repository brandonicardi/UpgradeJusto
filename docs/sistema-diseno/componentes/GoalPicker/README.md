# GoalPicker

Grupo de opciones grandes para elegir qué quiere lograr la persona, contado en sus palabras y no en componentes.

**Qué aporta quien lo usa:** la pregunta, la lista de objetivos (texto de uso cotidiano) y cuál está elegido.

- Cada opción es un botón con `aria-pressed`; elegida: fondo `pino-suave`, borde y tilde `pino`.
- Una sola opción por defecto. Si el producto admite varias, la pregunta lo dice («Elegí todas las que quieras»).
- Entre 3 y 5 opciones. Los textos empiezan con verbo: «Jugar mejor», «Trabajar más rápido».
