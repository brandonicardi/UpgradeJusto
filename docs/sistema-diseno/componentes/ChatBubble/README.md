# ChatBubble

Burbujas de la charla con el asistente, con sugerencias rápidas y el cuadro para escribir.

**Qué aporta quien lo usa:** los mensajes (de la persona o del asistente), los veredictos que devolvieron las herramientas y entre dos y cuatro sugerencias de próxima pregunta.

- Persona: a la derecha sobre `pino-suave`. Asistente: a la izquierda sobre `papel-alto` con `linea`, en `cuerpo` con interlineado amplio.
- El asistente explica; el veredicto que muestra es el del motor de compatibilidad, con el componente `Verdict`.
- Las sugerencias (`uj-chip`) arrancan la conversación: frases cortas en primera persona.
- El cuadro para escribir es una píldora con el botón de enviar adentro; el placeholder invita, no instruye.
